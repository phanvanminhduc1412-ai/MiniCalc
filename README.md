# 🧮 MiniCalc – The Ultimate Web Calculator

**MiniCalc** là website máy tính đa chức năng với nhiều chế độ tính toán, giao diện tùy biến và hệ thống User/EXP giúp ghi nhận quá trình sử dụng.

## ✨ Features

### 🖥️ Multiple Calculator Modes

- **Scientific 570:** Máy tính khoa học với các phép toán cơ bản và nâng cao.
- **Scientific 580:** Hỗ trợ phương trình, thống kê và các công cụ toán học.
- **Advanced 880:** Các chức năng tính toán nâng cao.
- **Cute 8D:** Giao diện pastel siêu cute, animation và hiệu ứng độc đáo. Đây là chế độ mặc định.

### 👤 User System

- Tự động tạo username ngẫu nhiên khi truy cập lần đầu.
- Tùy chỉnh username bằng nút Edit.
- Đổi tên lần đầu miễn phí.
- Những lần đổi tên tiếp theo yêu cầu hoàn thành thêm phép tính.
- Lưu thông tin người dùng bằng LocalStorage.

### ⭐ EXP System

- Mỗi phép tính thành công nhận được 1 EXP.
- Tích lũy EXP không giới hạn.
- Theo dõi tổng số phép tính.
- Theo dõi tiến độ mở khóa quyền đổi tên.

### 📜 Calculation History

- Lưu lịch sử tính toán.
- Xem lại kết quả.
- Xóa từng phép tính hoặc toàn bộ lịch sử.

### ⚙️ Settings

- Bật/tắt âm thanh.
- Tùy chỉnh hiệu ứng.
- Chọn giao diện.
- Quản lý dữ liệu cá nhân.

## 🚀 Installation

Không cần cài đặt thư viện hoặc backend.

1. Tải repository về máy.
2. Mở thư mục dự án.
3. Chạy file `index.html` bằng trình duyệt.

## 💾 Data Storage

MiniCalc sử dụng LocalStorage để lưu:

- Username
- Total EXP
- Total Calculations
- Rename Progress
- Calculation History
- Selected Calculator Mode
- User Settings

**Lưu ý:** Dữ liệu được lưu trên trình duyệt và thiết bị hiện tại, không tự động đồng bộ giữa các thiết bị.
